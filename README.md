# the-time-and-the-death

日本時間だけを表示する、丸いアナログ時計のシンプルなPWAです。
深夜の作業や考え事のお供に。

## 特徴

- 画面いっぱいに表示される丸いアナログ時計
- 常に日本標準時（UTC+9）を表示（端末のタイムゾーン設定に関わらず）
- ライトモード
- iPhoneのホーム画面に追加してアプリのように使える（PWA対応）
- オフラインでも起動できる（Service Workerによるキャッシュ）

## 使い方

1. https://lyrac.jp/the-time-and-the-death/ を開く
2. 共有ボタン →「ホーム画面に追加」を選ぶ
3. ホーム画面のアイコンから起動すると、丸時計がフルスクリーンで表示される

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 時計本体（HTML/CSS/JS） |
| `manifest.json` | PWAの設定ファイル（アプリ名・アイコン・起動設定など） |
| `sw.js` | Service Worker（オフライン対応用のキャッシュ処理） |
| `icon-192.png` / `icon-512.png` | ホーム画面用アイコン |
